# 拼豆图生成器（beadify）

一个纯前端的小工具：上传图片后自动转成“拼豆/拼豆像素图”效果，并可下载 PNG + 配色清单。

## 使用

### 方式 1：直接打开
双击打开 `beadify/index.html` 即可使用（推荐用 Chrome / Edge）。

### 方式 2：本地起一个静态服务（可选）
如果你希望更稳定（例如一些浏览器对本地文件的限制），可以在仓库根目录执行：

```bash
python3 -m http.server 5173
```

然后访问：
`http://localhost:5173/beadify/`

## 功能
- 上传图片并按“横向颗数（列）”自动等比缩放
- 颜色量化到内置色板（Perler 72 色 / Hama 72 色 / 灰度 72 色；支持抖动 / 不抖动）
- 支持“去彩点”后处理（减少人脸/皮肤区域彩色噪点）
- 支持“抠图（去背景）”：简单模式（背景较干净时效果好）/ 智能人像模式（需联网加载模型）
- 支持“卡通化”：先对真人照片做平滑 + 色阶简化 + 边缘线条，再转拼豆图
- 拼豆圆点渲染（可显示网格）
- 下载 PNG
- 导出配色清单（CSV）
- 下载打印版 PNG（带网格 + 行/列坐标 + 格内编号）
