# beadify

这个仓库目前包含三个同级项目：

- `rag/`：一个可运行的 RAG v0 骨架（FastAPI + Postgres/FTS）
- `beadify/`：拼豆图生成器（纯前端网页，上传图片自动转拼豆效果并下载）
- `beadify_py/`：拼豆模板生成器（Python/Pillow + pandas，输出模板 PNG + Excel 用量清单）

## 快速入口

### 拼豆图生成器
- 直接打开：`beadify/index.html`
- 说明文档：`beadify/README.md`

### 拼豆模板（Python）
- 说明文档：`beadify_py/README.md`
